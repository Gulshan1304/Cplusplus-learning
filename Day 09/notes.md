# Arrays
An Arrays is a collection of elements of the same data type storesin contigupus memory
locations.It allows you to store multiple values under one variable name.

##Why use an array?
Without an array:

int marks1 = 85;
int marks2 = 90;
int marks3 = 78;
int marks4 = 88;
int marks5 = 95;

with an array:
int marks[5] = {85, 90, 78, 88, 95};
##Syntax
data_t ype array_name[size];

## Types of Arrays
### 1.One-Dimentional Array:
Stores values in a single row.
### 2.Two-Dimensional Array:
Represent rows and column (Matrix).
### 3. Multi-Dimensional Array:
An Array with more than two dimentions.

## Advantages of Arrays
1. Store multiple values using one variable.
2. Easy traversal using loops.
3. Fast access using index (O(1)).
4. Memory is allocated continuously.

## Disadvantages
1. Fixed size.
2. Can store only one data type.
3. Inserting or deleting elements is not efficient.
