# Variables

A variable is a container used to store data in memory.

## Syntax of Variable


datatype variableName = value;
```

## Example

int marks = 95;
```

---

# Data Type

A data type is used to define the type of data that a variable can store in a program.

---

# Types of Data Types

    1. Integer Data Type (`int`)
    2. Float Data Type (`float`)
    3. Double Data Type (`double`)
    4. Character Data Type (`char`)
    5. String Data Type (`string`)
    6. Boolean Data Type (`bool`)

---

## 1. Integer Data Type (`int`)

An integer data type is used to store whole numbers without decimal points.

---

## 2. Float Data Type (`float`)

A float data type is used to store decimal numbers.

---

## 3. Double Data Type (`double`)

A double data type is used to store large and more accurate decimal values.

### Why Use Double?

Because it gives more precision than `float`.

---

## 4. Character Data Type (`char`)

A character data type is used to store a single character.

---

## 5. String Data Type (`string`)

A string data type is used to store text or multiple characters.

---

## 6. Boolean Data Type (`bool`)

A boolean data type is used to store true or false values.

# Type Casting 

 Type casting is the process of converting one data type into another data type.

 ## Example 
     int → float
    float → int
    char → int

# Types of Type Casting

1. Implicit Type Casting
2. Explicit Type Casting

## 1. Implicit Type Casting

Automatic conversion done by compiler.

## 2. Explicit Type Casting

Manual conversion done by programmer.
